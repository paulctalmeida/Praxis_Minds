# Clients

One folder per client, named in lowercase with hyphens (e.g. `silva-logistics/`). Create it by copying [`_template/`](_template/).

## ⚠️ Privacy rules for this folder

This repository is for **business planning and non-sensitive project records** (proposals, SOWs, notes, results, case studies).

- **Keep this repository private.**
- **Do not store** confidential client documents, personal data (employee/customer records), credentials, API keys, or contracts containing personal details here. Keep those in an access-controlled company drive (or the client's own systems), and link to them instead.
- Anonymize sample data before saving anything derived from it.
- Delete client folders when the contract requires data deletion.
