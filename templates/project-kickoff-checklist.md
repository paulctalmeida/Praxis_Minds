# Project Kickoff Checklist

Copy into the client folder at the start of every project. See [06 – Delivery Process](../plan/06-delivery-process.md) for the full lifecycle.

## Before kickoff (admin)
- [ ] Proposal accepted (option: ________)
- [ ] MSA signed (or already in place)
- [ ] SOW signed
- [ ] DPA signed (if personal data is involved)
- [ ] NDA signed (if requested)
- [ ] Deposit invoice sent → **paid** (work starts after payment)
- [ ] Client folder created from `clients/_template/`
- [ ] Client Claude Project created (company profile, SOW, glossary)
- [ ] Kickoff meeting booked; agenda sent
- [ ] Welcome email sent (what happens next, who we need, what to prepare)

## Kickoff meeting agenda (60 minutes)
1. **Introductions & roles** (5 min): client project owner, users, IT contact
2. **Goals & success metrics** (10 min): confirm targets from the SOW
3. **Baseline measurement** (10 min): measure/record the current state now (hours, volumes, errors, costs)
4. **Current process walkthrough** (15 min): screen share or demo; book shadowing/recording sessions
5. **Scope check** (5 min): read out the in-scope and out-of-scope lists
6. **Access & data** (5 min): what we need, by when, and how it's shared securely
7. **Communication** (5 min): weekly update day/time, channel (email/Teams/Slack), decision process
8. **Next steps** (5 min): owners and dates

## Risks to check
- [ ] Is the project owner really available?
- [ ] Any dependency on a third party (software vendor, IT provider)?
- [ ] Personal or sensitive data? (Minimization, DPA, DPIA needed?)
- [ ] Any high-risk AI use (employment decisions, credit, etc.)? → stop and review
- [ ] Is the user group on board? (Involve them early to avoid resistance)

## After kickoff
- [ ] Send kickoff summary within 24 hours (decisions, owners, dates)
- [ ] Add milestones to your calendar
- [ ] Schedule weekly updates and demos
- [ ] Record baseline metrics in the client folder (`results.md`)
